ZedArduino IDE — быстрый редактор с инструментами Arduino IDE
================================================================

Запуск: ZedArduinoIDE.exe  (или ярлык «ZedArduino IDE»)
Установка (необязательно): правой кнопкой по install.ps1 -> «Выполнить с помощью PowerShell»
Удаление: uninstall.ps1 (настройки сохраняются; -RemoveSettings удалит и их)

Что нужно для работы:
  • Windows 10/11 x64
  • arduino-cli — программа найдёт его автоматически, если установлена Arduino IDE,
    либо скачает при нажатии «Установить» в менеджере плат. Свой путь можно указать
    в Настройках -> Ардуино.
  • Платы/ядра и библиотеки берутся из стандартных папок Arduino:
    %LOCALAPPDATA%\Arduino15  и  Документы\Arduino\libraries

Быстрый старт:
  1. Откройте папку со скетчем (.ino) или создайте новый.
  2. Выберите плату в поиске плат сверху и порт.
  3. Ctrl+B — проверить, Ctrl+U — загрузить, Ctrl+M — монитор порта.
  4. Настройки и ИИ — иконки справа сверху / Ctrl+, и Ctrl+Shift+A.

ИИ-чат: вставьте свой адрес API, ключ и модель в Настройках -> ИИ.
Ключ хранится только локально; действия с файлами выполняются лишь после
подтверждения и только внутри папки проекта.

Горячие клавиши и подробности — README.md.
