# Дорожная карта

Документ отражает реальное состояние 1.0.0 и планы, а не обещания сроков. Приоритеты: **P0** — качество и предотвращение регрессий, **P1** — завершение ключевых сценариев IDE и распространения, **P2** — расширение платформы и экосистемы.

## 1. Что уже есть в 1.0.0

- Редактор CodeMirror 6: подсветка C/C++/Arduino, дерево проекта, вкладки, поиск/замена, поиск по проекту, автосохранение, отступы, перенос строк, подсветка активной строки.
- Автодополнение: Arduino API (пины, `Serial`, строки, математика, прерывания, константы, типы, сниппеты), символы текущего файла и всего проекта, member-access, быстрый локальный отклик.
- Платы и ядра: список FQBN, настройки платы, определение подключённых плат и портов, менеджер ядер, дополнительные URL менеджера плат, обновление индекса.
- Компиляция и загрузка через `arduino-cli`, потоковый вывод, разбор ошибок/предупреждений, кликабельные проблемы, отмена процесса.
- Монитор порта: нативный `serialport`, fallback на `arduino-cli monitor`, скорость, окончание строки, автоскролл, метки времени, отправка (в нативном режиме).
- Менеджер библиотек: поиск, установка, удаление, установка из ZIP, дополнительные папки библиотек (сканирование и передача в `--libraries`).
- ИИ-чат: произвольный OpenAI-совместимый endpoint, потоковый ответ, системный промпт, temperature/max tokens, инструменты чтения/записи/создания/удаления/листинга с обязательным одобрением и песочницей проекта.
- Интерфейс: русский по умолчанию, английский; тёмная/светлая/кастомная тема (20 цветов), акцент, масштаб UI, шрифт и размер редактора; редактор темы.
- Портативная Windows-сборка без установщика, CI build и release workflows, MIT-лицензия, документация.

## 2. Ближайшие версии (по приоритетам)

### P0 — качество и CI

| Задача | Зачем | Критерий готовности |
| --- | --- | --- |
| Юнит-тесты Vitest | Защитить парсер символов, утилиты, настройки, песочницу путей | `npm run test`, покрытие ключевых модулей `shared`/`main` |
| E2E-тесты Playwright | Проверять запуск Electron, открытие проекта, редактор, настройки, ИИ с mock-сервером | Стабильный smoke-набор в CI на Windows |
| ESLint + Prettier + CI lint | Единый стиль и раннее обнаружение ошибок | `npm run lint`, отдельный job в `build.yml` |

Без этих шагов дальнейшие крупные изменения будут рискованными; тесты и линтер — фундамент для остального списка.

### P1 — завершение IDE и распространения

| Задача | Описание | Зависимости |
| --- | --- | --- |
| Полноценный встроенный терминал | Панель с `cmd`/PowerShell через `conpty`/`node-pty`, рабочий каталог проекта, несколько сессий, история | Новый процессный слой, отдельный `PanelView` |
| Установщик (NSIS/MSI) | Установка в `%LOCALAPPDATA%\Programs`, ярлыки, удаление, обновление | Подпись кода |
| Подпись кода | Убрать предупреждение SmartScreen, подготовить автообновление | Сертификат, шаг `signtool` в release |
| Автообновление через GitHub Releases | Проверка версии, скачивание, установка; канал stable/beta | Подписанные сборки, `electron-updater` или аналог |
| Include-completion из установленных библиотек | Подсказывать `#include <...>` по заголовкам установленных библиотек | Данные `libraryHeaders` уже в контракте индекса, нужен сбор и кэш |
| Группировка и избранное в выборе платы | Группы по ядру/производителю, недавние и избранные платы | UI `BoardPicker`, настройки |
| Проверка обновлений библиотек | Показывать доступные версии и обновлять по одной | `lib list`/`lib search`, сравнение версий |
| Опциональная crash-репортинг без телеметрии | Локальный отчёт или отправка только по явному согласию | Политика приватности, consent UI |
| Accessibility pass | Фокус, клавиатурная навигация, aria, контраст, масштаб | Аудит диалогов и панелей |

### P2 — расширение

| Задача | Описание |
| --- | --- |
| OTA-загрузка | `arduino-cli upload -p <network-port>` и настройки OTA для совместимых плат; сначала исследование |
| Браузер примеров скетчей | Каталог `examples/` и библиотечных примеров с предпросмотром и копированием в проект |
| Подключаемые AI-провайдеры | Абстракция провайдера (OpenAI-совместимый, локальные серверы, свои заголовки), профили |
| UI на языках помимо ru/en | Расширение `Lang`, словари, плюрализация, локализация нативного меню |
| macOS/Linux сборки | Адаптация путей, `arduino-cli`, `serialport`, упаковки; Electron уже кроссплатформенный, но код и CI — Windows-only |
| Дополнительные улучшения редактора | Форматирование, `clang-format`, диагностика на лету, Include Path |

## 3. Не входит в планы

- Собственный AI-бэкенд, прокси или хранение ключей на сервере.
- Встроенный `arduino-cli` в поставку (GPLv3; текущая модель — внешний инструмент).
- Телеметрия, аналитика и реклама.
- Полная замена Arduino IDE для сложных сценариев (отладчик, продвинутые менеджеры пакетов) в ближайших версиях.
