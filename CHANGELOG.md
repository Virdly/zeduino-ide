## [Unreleased]

### Добавлено

- **Ctrl+T — автоформат (выравнивание) кода** для C/C++/Arduino: отступы по блокам, `case`/`default`,
  продолжения выражений, комментарии и препроцессор; форматируется выделенный фрагмент или весь файл.
  Пункт «Выровнять код» также добавлен в меню «Правка».
- **edit_file** — точечное редактирование файла (замена фрагмента `old_text` → `new_text`, с `replace_all`
  и устойчивым к пробелам поиском) вместо полной перезаписи.
- **list_dir** с `recursive`/`depth` — быстрое дерево папок и файлов.
- **Доступ ИИ к библиотекам**: `list_libraries` показывает установленные библиотеки и их пути; чтение,
  правка и создание файлов внутри папок библиотек разрешены, изменение — только после подтверждения.
- **run_python** — запуск Python-скрипта (файл или код) с тайм-аутом и выводом, только после разрешения.
- **run_shell** — команды PowerShell/cmd с тайм-аутом и выводом, только после разрешения и с пометкой
  «Опасное действие».
- **web_search / web_fetch** — поиск и чтение веб-страниц; провайдер поиска и ключ (Brave/Tavily) настраиваются,
  DuckDuckGo работает без ключа. Приватные/локальные адреса для `web_fetch` заблокированы.
- **update_plan** — ИИ составляет план задачи и ведёт его в панели чата (прогресс и статусы шагов,
  автообновление без подтверждения).

## [1.0.0] — 2026-11-27

Первая публичная версия.

### Добавлено

- **Редактор** на CodeMirror 6: подсветка C/C++/Arduino, вкладки, дерево файлов, поиск/замена,
  поиск по проекту, автосохранение, перенос строк, настройка отступов и шрифта.
- **Автодополнение**: ~190 записей Arduino API (функции, константы, типы, методы `Serial`),
  символы из всех файлов проекта (функции, переменные, объекты, макросы, структуры), сниппеты,
  дополнение по любому слову; индекс обновляется по изменению файлов.
- **Платы**: поиск по названию/FQBN, настройки платы (процессор/вариант), автоопределение портов,
  список подключённых плат.
- **Ядра**: менеджер ядер (установка/удаление), дополнительные ссылки менеджера плат (JSON),
  обновление индекса.
- **Сборка**: «Проверить» и «Загрузить», прогресс, размер прошивки и ОЗУ, подсветка ошибок в редакторе,
  панель «Вывод» и вкладка «Проблемы» с переходом на строку.
- **Монитор порта**: скорость, отправка строк, окончание строки, автоскролл, метки времени;
  нативный `serialport` с резервным режимом через `arduino-cli monitor`.
- **Библиотеки**: менеджер установленных, поиск и установка из реестра, удаление, установка из ZIP,
  дополнительные папки библиотек (показываются в списке и передаются в сборку).
- **ИИ-чат** с произвольным OpenAI-совместимым API: адрес, ключ, модель, системный промт,
  стриминг, отмена запроса, очистка чата, Markdown с копированием.
- **Инструменты ИИ** (`read_file`, `write_file`, `create_file`, `delete_file`, `list_dir`) с
  подтверждением каждого действия и песочницей в пределах папки проекта.
- **Темы**: тёмная, светлая, своя (все 20 цветов), акцент, масштаб интерфейса; русский и английский язык.
- **Портативная сборка** для Windows x64, `install.ps1`/`uninstall.ps1`, примеры скетчей, CI-сборка.
- **Офлайн-режим arduino-cli**: бинарник можно положить в папку `tools` рядом с программой — он будет найден автоматически.

### Исправлено

- Поиск `arduino-cli`: `PATH`, установленная Arduino IDE, локальная папка `tools`, скачивание по кнопке.
- Определение скетчбука Arduino: если «Документы» перенаправлены в OneDrive, используется реальная папка
  с библиотеками (`%USERPROFILE%\Documents\Arduino`), а не пустая папка OneDrive.
- Библиотеки из дополнительных папок теперь видны в менеджере библиотек (раньше использовались только
  при компиляции).
- Разбор списка плат переведён на компактный текстовый вывод arduino-cli (раньше JSON на 20+ МБ мог
  обрезаться и ломать список).
- Локализация вывода arduino-cli принудительно английская — стабильный разбор размера прошивки и ошибок.
- Настройки устойчивы к BOM в `settings.json`.
- Всплывающие подсказки автодополнения больше не обрезаются нижней панелью.
- `project.onFsChanged` в preload теперь действительно вызывает подписчика.
